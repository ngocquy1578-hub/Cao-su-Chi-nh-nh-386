# Bộ file Export Cao su CN386

Bộ export chứa dữ liệu thực có trong hệ thống tại thời điểm trích xuất. File tài khoản nội bộ đã loại bỏ mật khẩu băm và mọi bí mật. File Nhật ký hoạt động phục vụ truy vết; file Báo cáo rà soát tóm tắt kiểm tra tính toàn vẹn, tương thích import/export và bản vá đã thực hiện.
